Copie este ficheiro para a raiz do projeto (mesmo nível do package.json).
Execute os comandos EM ORDEM, um a um, no terminal (PowerShell ou Bash).

--------------------------------------------------------------------------------
PRÉ-REQUISITOS (instale uma vez no PC)
--------------------------------------------------------------------------------
- Node.js 20+  (verifique: node -v)
- pnpm OU npm (o projeto usa npm)
- Conta Supabase + projeto criado
- Conta Cloudflare (R2 + Workers/Pages para deploy via OpenNext) — opcional se só testar local sem imagens

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
ESTRUTURA CHAVE (para orientação)
--------------------------------------------------------------------------------
app/              # Páginas Next.js (App Router)
  admin/          # Backoffice (protegido por middleware)
  api/            # Route handlers (auth/callback)
  actions/        # Server Actions (upload, logout)
components/       # React components (client + server)
hooks/            # Custom hooks (favorites, vehicle-form)
lib/              # Utils (supabase clients, R2)
supabase/         # Scripts SQL (setup.sql = canónico)
middleware.ts     # Proteção /admin + refresh sessão
.claude/settings.json  # Hook PostToolUse → auto CHANGELOG
DOCUMENTO_PROJETO.txt  # Documentação completa do projeto

--------------------------------------------------------------------------------
SE ALGO FALHAR
--------------------------------------------------------------------------------
- Erro "Missing Supabase env vars" → .env.local mal preenchido ou não reiniciou dev
- Erro 401/RLS no admin → user não tem role='admin' na tabela profiles
- Imagens não aparecem → R2 credentials erradas ou bucket não público
- Hook não dispara → execute PASSO 6 (/hooks ou restart claude)
- "policy already exists" no SQL → use DROP POLICY IF EXISTS antes (setup.sql já faz)
