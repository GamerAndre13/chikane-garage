Troubleshooting

❌ Build falha no Cloudflare Pages:
Verifique o Build Log no dashboard. Causas comuns:
• Variáveis de ambiente não configuradas (Supabase, R2) — configure em Pages → Settings → Environment variables
• Node version incompatível — confirme que Pages usa Node 18+
❌ Site mostra "hello world" ou página antiga:
• Aguarde 2–3 min após o deploy ser marcado como "Success"
• Limpe cache do navegador (Ctrl+Shift+Delete)
• Verifique que o domínio aponta para Cloudflare Pages (DNS → chikanegarage.blog deve ter record CNAME para Pages)
⚠ next.config.ts e o deploy OpenNext
O projeto NÃO usa output: "standalone". O deploy de produção é via OpenNext (npm run deploy → @opennextjs/cloudflare), que gera o bundle em .open-next/ servido pelo wrangler.toml (main = ".open-next/worker.js", R2 binding VEHICLE_IMAGES). Para preview local: npm run preview. Depois de mudar bindings/vars, corra npm run cf-typegen para regenerar cloudflare-env.d.ts.
