✓ Passo 2: Confirmar/atualizar wrangler.toml

Verifique se o wrangler.toml no repositório está correto para Cloudflare Pages + Next.js standalone:

O ficheiro deve ser:

OU, se Pages ainda não encontra a app, use:

Troubleshooting avançado

Se o Build Log mostra erro:
  • "Missing Supabase": variáveis não foram configuradas no Cloudflare (repetir Passo 1)
  • "Cannot find module": dependências não instaladas (Pages usa npm ci, confirme que package-lock.json está no git)
  • "Next.js error": build falha localmente também (testar com npm run build local)
